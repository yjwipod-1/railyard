# Epic Format

Epic files live under:
- `docs/domain/epics/`
- `docs/system/epics/`

Recommended filename:
- `<epic_id>.md`

## Required Frontmatter Fields

- `epic_id`
- `lane`
- `status`
- `priority`

## Optional Frontmatter Fields

- `source`
- `linked_ticket_id`

## Required Body Sections

- `# <EPIC-ID> - <Title>`
- `## Summary`
- `## Done Definition`

## Optional Body Sections

- `## Preferred Entrypoints`
- `## Notes`
- `## Blocked By Epics`
- `## Blocked By External`

Use bullet lists for list sections.
